Introduction

Hi, I'm bechryko. Welcome to my Name Generator! This application is built to let you generate names based on different algorithms, which you can read about in the Generators section. These algorithms are highly configurable, so if you have a name idea, or a half finished name, this application might help you to finish it and give it to your fictional character.

The icon of the application was created on Flaticon using an icon by Alfredo Creates. Take a moment to appreciate his work, or try the site yourself to get some amazing icons!
