Generators

Here you can find everything about all the generator algorithms and their configuration.

Japanese generator algorithm create

This algorithm is based on the Japanese letters. It is a syllabic alphabet, which means that letters placed after each other create an easily pronounceable word - a name.

The minimum and maximum length values configure how many Japanese letters can be placed in the name. The length can be between {{ configPropertyBounds.lengthInSyllables.min }} and {{ configPropertyBounds.lengthInSyllables.max }}.

The Disable letter weights checkbox makes it possible to ignore the default weights for each Japanese letter. By default, there is a weight assigned to each letter, based on real Japanese texts. By checking this rule, these weights are not taken into account when choosing each letter for the generated word.

Syllabic generator algorithm create

This algorithm creates syllables and places them after each other, resulting in a pronounceable name.

The minimum and maximum length values configure how many syllables can be placed in the name. The length can be between {{ configPropertyBounds.lengthInSyllables.min }} and {{ configPropertyBounds.lengthInSyllables.max }}.

The excluded and included letters fields are used to configure the used letters. These can't be both used, you can only exclude or include letters to generate the name from. Also, if there are not enough letters to generate the name from, the generator will use the default letters and pop up a warning.

The Ignore voiced-unvoiced neighbors checkbox is used to configure if the generator should ignore the voiced-unvoiced neighbor rule. This rule means that after a voiced/unvoiced consonant, the next consonant can't be its pair. For example, after a letter 'g' the next consonant can't be 'k', because they are a voiced-unvoiced pair. If this checkbox is checked, the generator will ignore this rule and may generate names with voiced-unvoiced neighbors.

The Syllable alleviation checkbox turns on and off the syllable alleviation. This rule prevents two or three neighboring syllables to have too many or too few consonants. Overall, this rule helps prevent names with only short or only long syllables.

The Disable letter weights checkbox makes it possible to ignore the default weights for each letter. By default, there is a weight assigned to each letter, based on English texts. By checking this rule, these weights are not taken into account when choosing each letter for the generated word.

Regular generator algorithm create

This algorithm uses the full potential of the application's special regular language. It has a lot of customizability, although it is built more for customization, than to generate names with the basic configs. So with this algorithm, it is crucial to be familiar with the configuration options, and use them for the best, custom results!

The minimum and maximum length values configure how many letters can be placed in the name. The length can be between {{ configPropertyBounds.lengthInLetters.min }} and {{ configPropertyBounds.lengthInLetters.max }}.

The excluded and included letters fields are used to configure the used letters. These can't be both used, you can only exclude or include letters to generate the name from. Also, if there are not enough letters to generate the name from, the generator will use the default letters and pop up a warning.

The Ignore voiced-unvoiced neighbors checkbox is used to configure if the generator should ignore the voiced-unvoiced neighbor rule. This rule means that after a voiced/unvoiced consonant, the next consonant can't be its pair. For example, after a letter 'g' the next consonant can't be 'k', because they are a voiced-unvoiced pair. If this checkbox is checked, the generator will ignore this rule and may generate names with voiced-unvoiced neighbors.

The regular name start/end/skeleton lets you customize how you want your name to be built. The start and end only applies to the respective part of the name, while the skeleton defines the whole name (overriding the set length options).

The regular language, which you can use in the above fields, consists of four types of characters: letters, basic regular symbols, regular reference symbols and regular letter sets. The letters are explicitly telling the generator to put the given letter in the given place in the name. With the basic regular symbols you can define sets of letters to put in the given place. The {{ regulars.wildcard }} (wildcard) symbol tells that any letter (taking into account other configuration rules) can be placed there, while {{ regulars.vowel }} and {{ regulars.consonant }} mean a random vowel or consonant, respectively. Using regular reference symbols you can reference to other parts of your name, using non-negative integer numbers. (Indexing starts from 0.) For an example, if your regular structure is "+--0", the first letter will be a random vowel, the second and third a random consonant which are independent, and the last letter references the first (the one with index 0), so they will always be the same. One possible name generated with this structure is "Ansa". (If you are using references with higher index than 9, you have to put curly brackets around them, like {{ "{11}" }}.)

Note that, regular name start and end are regular strings on their own. So if you write a 0 in the regular name end, it will reference the first character of the regular name end, not the whole name! If you want to create an external reference (to reference a character that is not in the current regular string), use the following syntax: {{ "{e\}" }}! For example, if you want to reference the 2nd character in the regular start, from the regular end, you have to use a {{ "{e1}" }} reference.

Furthermore, you can use regular letter sets. With the syntax (bcd) you can define such set, so during generation one letter is used from this set randomly, with equal chance. So the regular skeleton "a(dtv)a" can be "Ada", "Ata" or "Ava". Note that, in regular letter sets currently you can only use letters, no regular characters.

The Disable letter weights checkbox makes it possible to ignore the default weights for each letter. By default, there is a weight assigned to each letter, based on English texts. By checking this rule, these weights are not taken into account when choosing each letter for the generated word.

Phonetic generator algorithm create

This generator is based on Tom Shawver's Phonetic NPM package, which creates random, pronounceable words. This generator is only a wrapper around that package to integrate it into the name generator, so all credits go to Tom Shawver.

The minimum and maximum length values configure how many syllables can be placed in the name. The length can be between {{ configPropertyBounds.lengthInSyllables.min }} and {{ configPropertyBounds.lengthInSyllables.max }}. Note that this is a phonetic syllable amount, the actual one can be outside the set bounds.
