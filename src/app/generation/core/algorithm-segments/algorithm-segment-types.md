# Algorithm Segment types

The segments can be split into multiple groups based on their purpose, and their input and output type.

- structure generator: generates a regular structure from scratch
- structure mutator: changes a regular structure based on rules
- wildcard resolver: clears wildcard regulars from a regular structure
- finalizer: clears all regulars from a regular structure to create a name
- mutator: changes an already generated name based on rules
- creator: creates a name without any intermediate generation steps
